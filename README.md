## 🚀 Возможности

### Организация мероприятий
- ✅ Создание, редактирование и управление мероприятиями
- ✅ Категории, локации, даты, цены
- ✅ Статусы: черновик, опубликовано, отменено, завершено
- ✅ Фильтрация по категории и городу

### Билетная система
- ✅ Покупка билетов
- ✅ Уникальные QR-коды для каждого билета
- ✅ Передача билетов между пользователями (с запросом и подтверждением)
- ✅ Проверка билетов организаторами через сканирование QR (камера смартфона)
- ✅ Отметка билетов как использованных

### Блокчейн-гарантия
- ✅ Криптографический хеш для каждого билета
- ✅ Запись хешей в блокчейн-сеть (эмуляция, с возможностью перехода на реальную сеть)
- ✅ Проверка подлинности билетов и референсов
- ✅ Загрузка референсов (изображений) с фиксацией в блокчейне

### Маркетплейс мастеров
- ✅ Профили мастеров с описанием, портфолио, рейтингом
- ✅ Отзывы и оценки (от 1 до 5 звёзд)
- ✅ Возможность оставлять отзывы только авторизованным пользователям
- ✅ Поиск мастеров, сортировка по рейтингу

### Пользователи и профили
- ✅ Регистрация и авторизация (email/никнейм + пароль)
- ✅ Хеширование паролей (Werkzeug)
- ✅ Профиль пользователя с аватаркой, биографией, статистикой
- ✅ Редактирование профиля (никнейм, аватар, описание)
- ✅ Просмотр своих билетов, мероприятий и отзывов

### Интерфейс и дизайн
- ✅ Две цветовые темы: светлая и тёмная (переключение с сохранением в localStorage)
- ✅ Адаптивный дизайн (мобильные устройства)
- ✅ Бургер-меню для навигации
- ✅ Тосты (уведомления) с автоматическим исчезновением
- ✅ Градиентная палитра (оранжевый → фиолетовый)
- ✅ Анимированный граф на главной странице (частицы с линиями)
- ✅ Typing-эффект для заголовка

### Дополнительные страницы
- ✅ «О проекте» – миссия, ценности, команда
- ✅ «Помощь» – подробное руководство
- ✅ «Правила сообщества» – правила и санкции
- ✅ «Контакты» – все способы связи
- ✅ Страница 404 с интерактивной игрой «Змейка» (градиентная линия, управление мышью)

## 🛠 Технологии

| Компонент | Технология |
|-----------|------------|
| **Backend** | Python 3.10+, Flask 2.3.x |
| **Database** | SQLite (по умолчанию), возможен переход на PostgreSQL |
| **ORM** | SQLAlchemy 2.x + Flask-Migrate |
| **Frontend** | HTML5, CSS3 (чистый CSS, без фреймворков) |
| **QR-коды** | qrcode + Pillow |
| **Markdown** | markdown, bleach (санитизация) |
| **Аутентификация** | Werkzeug (хеширование паролей) |
| **Локализация** | Flask-Babel (сервер), JSON (клиент) — в будущем |
| **Блокчейн** | эмуляция через хеши и транзакции (web3.py в планах) |
| **Визуализация** | Canvas (граф, змейка) |

## 📦 Установка и запуск

### Требования
- Python 3.10 или выше
- pip

### Шаги

1. **Клонировать репозиторий**
```bash
git clone https://github.com/YFG-CodeBase/yfg.su.git
cd yfg.su
```

2. **Создать и активировать виртуальное окружение**
```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux / macOS:
source venv/bin/activate
```

3. **Установить зависимости**
```bash
pip install -r requirements.txt
```

4. **Инициализировать базу данных**
```bash
python init_db.py
```

5. **(Опционально) Наполнить базу тестовыми данными**
```bash
python injector.py
```
Это создаст 24 пользователя, 20 мероприятий, билеты, мастеров, отзывы и блокчейн-записи.

6. **Запустить приложение**
```bash
python app.py
```

7. **Открыть в браузере**
```
http://127.0.0.1:5000
```

├── injector.py            # Наполнение БД тестовыми данными

├── .env                   # Переменные окружения (секретный ключ и т.п.)

│   └── yfg.db

## 🔗 API Endpoints

| Маршрут | Метод | Описание |
|---------|-------|----------|
| `/` | GET | Главная страница |
| `/events` | GET | Список мероприятий (с фильтрацией) |
| `/event/<id>` | GET | Детальная страница мероприятия |
| `/event/<id>/buy` | POST | Покупка билетов |
| `/tickets` | GET | Мои билеты |
| `/ticket/<id>/qr` | GET | QR-код билета |
| `/ticket/<id>/transfer` | GET, POST | Передача билета |
| `/transfer/<id>/<action>` | POST | Принять/отклонить передачу |
| `/ticket/<id>/use` | POST | Отметить билет как использованный |
| `/masters` | GET | Список мастеров |
| `/master/<id>` | GET | Профиль мастера |
| `/master/<id>/review` | POST | Добавить отзыв |
| `/blockchain` | GET | Блокчейн-записи пользователя |
| `/blockchain/upload` | POST | Загрузить референс |
| `/profile` | GET | Профиль пользователя |
| `/profile/edit` | GET, POST | Редактирование профиля |
| `/login` | GET, POST | Вход |
| `/register` | GET, POST | Регистрация |
| `/logout` | GET | Выход |
| `/about`, `/help`, `/rules`, `/contacts` | GET | Статические страницы |
